# 项目进展日志（log）

记录 LabFlow 的真实开发进展、关键决策与验证证据，按日期归档。日志与 Git 提交记录互为佐证：**先有实际工作，再写日志**，不补写、不虚构日期。

## 记录规范

| 项 | 约定 |
| --- | --- |
| 文件命名 | `YYYY-MM-DD.md`（同一天追加到同一文件，不新建 `-v2`） |
| 跨天续做 | 新建当天文件，在开头「承接」小节指向上一份日志 |
| 每条记录包含 | 目标 / 完成项 / 关键决策 / 验证证据 / 遗留问题与风险 / 下一步 |
| 证据原则 | 只写**实际执行过**的命令与结果；未验证的内容标注「未验证」 |
| 提交关联 | 记录中列出对应 commit 短号，便于追溯 |
| 敏感信息 | 不写真实密钥、真实数据库口令、他人个人信息 |
